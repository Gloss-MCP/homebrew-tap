# homebrew-tap

Homebrew tap for [Gloss](https://gloss-mcp.github.io/client/).

## Install

```sh
brew install gloss-mcp/tap/gloss
```

This is equivalent to:

```sh
brew tap gloss-mcp/tap
brew install gloss
```

## Links

- Project site: <https://gloss-mcp.github.io/client/>
- Source: <https://github.com/gloss-mcp/client>

## Maintenance

`Formula/gloss.rb` is generated by the release workflow in
[gloss-mcp/client](https://github.com/gloss-mcp/client) each time a release is
published. Do not edit it by hand; changes are overwritten on the next release.
